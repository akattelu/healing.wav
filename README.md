# healing.wav

A roguelike 2D game made with Love2D where you play as a cleric wielding healing waves to survive 10 increasingly difficult waves of undead enemies.

This is a submission for [Game Off 2025](https://itch.io/jam/game-off-2025)

## Running the Game

```bash
love .
```

Hot reloading is enabled via lick - changes to `.lua` files will automatically reload the game.

You can also visit https://healing-wav.vercel.app/ for a web-hosted version thats compiled with love.js.
